# คู่มือวิทยากร: เข้าใจผู้ใช้ก่อนสร้างนวัตกรรม

**สำหรับวิทยากรและผู้สวมบทบาทเท่านั้น ห้ามเผยแพร่ในหน้าบทเรียนสำหรับผู้เรียน**

ใช้คู่กับบทเรียน "เข้าใจผู้ใช้ก่อนสร้างนวัตกรรม (Design Thinking)" บน code.gogoboard.org

บัตรผู้ใช้จำลองเรื่องราวของคนในวัด โรงเรียน และหมู่บ้าน สามารถใช้จัดกิจกรรมได้ทั้งกับสามเณรและนักเรียนทั่วไป วิทยากรหรือคุณครูสวมบทบาทได้ทุกตัวละคร โดยไม่ต้องแสดงเป็นพระหรือสามเณร

---

## เตรียมตัว

- ผู้สวมบทบาทหนึ่งคนดูแล 2–3 ทีม คุณครูที่มากับผู้เรียนเหมาะจะทำหน้าที่นี้ เพราะรู้จักคนในชุมชนอยู่แล้ว
- จัดให้ทีมที่สัมภาษณ์ผู้ใช้คนเดียวกันนั่งใกล้กัน โดยให้ผู้สวมบทบาทนั่งตรงกลาง
- ให้ผู้สวมบทบาทอ่านบัตรล่วงหน้าและซ้อมกับวิทยากรหลักก่อนวันจัดกิจกรรม
- วิทยากรหลักทำหน้าที่คุมเวลาและเดินดูความคืบหน้าของแต่ละทีมตามรายการตรวจในแต่ละขั้น โดยไม่สวมบทบาท
- อุปกรณ์ที่ใช้: กระดาษ A4 ปากกาเมจิก และนาฬิกาจับเวลาที่แสดงบนจอ

**การแบ่งเวลา:** ควรให้เวลากับขั้นที่ 1 สัมภาษณ์ผู้ใช้มากที่สุด หากมีเวลาจำกัด ให้ลดเวลาบทสาธิตและขั้นที่ 3 คิดไอเดียลง แต่ไม่ควรตัดขั้นที่ 4 เล่าให้ผู้ใช้ฟัง

## สิ่งที่ต้องตรวจในแต่ละขั้น

| ขั้น | สิ่งที่ต้องตรวจ | ถ้าทีมยังทำไม่ได้ ลองถามว่า |
|---|---|---|
| 1 สัมภาษณ์ | จดคำพูดของผู้ใช้โดยใส่เครื่องหมายคำพูด "..." กำกับไว้ และสมาชิกทุกคนได้ถาม | "ผู้ใช้พูดไว้ว่าอะไรบ้าง ลองยกคำพูดมาให้ฟังหน่อย" |
| 2 สรุปปัญหา | วงกลมเรื่องที่ทำให้ทีมแปลกใจที่สุดไว้แล้ว ประโยคสรุปปัญหาไม่มีชื่ออุปกรณ์ และเหตุผลหลังคำว่า "เพราะ" มาจากการสัมภาษณ์ | "ก่อนสัมภาษณ์ เราคิดว่าปัญหาคืออะไร ตอนนี้เข้าใจต่างไปยังไง" / "ถ้าตัดคำว่าเครื่องออก ผู้ใช้อยากให้อะไรเกิดขึ้น" |
| 3 คิดไอเดีย | ทุกคนวาดได้อย่างน้อยคนละ 3 ไอเดีย และทีมตอบคำถามว่าไอเดียช่วยผู้ใช้ได้หรือไม่ ก่อนคิดว่าจะใช้ GoGo Board ทำอะไร | "ถ้าไม่ใช้ไฟฟ้าเลย จะแก้ยังไง" / "ไอเดียนี้ช่วยแก้ปัญหาที่เราสรุปไว้ได้ยังไง" |
| 4 เล่าให้ผู้ใช้ฟัง | อ่านประโยคสรุปปัญหาก่อนเล่าไอเดีย และจดสิ่งที่ผู้ใช้พูดต่อจากคำว่า "แต่" | "ผู้ใช้บอกอะไรที่เรายังไม่รู้บ้าง" |

**จุดที่พลาดบ่อยที่สุด:** ประโยคสรุปปัญหายังระบุอุปกรณ์ เช่น "ต้องการเครื่องเตือน ..." ตรวจข้อนี้ให้ครบทุกทีมก่อนเริ่มขั้นที่ 3

## บทสาธิต (ก่อนขั้นที่ 1)

ถ้ามีเวลา ให้สาธิตก่อนเริ่มสัมภาษณ์ เพื่อให้ผู้เรียนที่ไม่เคยทำ Design Thinking เห็นความต่างระหว่างคำถามที่ดีกับคำถามที่ไม่ดี

ให้วิทยากร 2 คนช่วยกันสาธิต คนหนึ่งสวมบทบาทเป็น **ครูมะลิ** อีกคนเป็นผู้สัมภาษณ์ บทครูมะลิไม่ได้อยู่ในบัตรผู้ใช้ จึงไม่มีทีมไหนรู้ปัญหาของผู้ใช้ในบัตรล่วงหน้า

**ข้อมูลครูมะลิ:** เป็นครูประจำชั้น ม.2 ห้องเรียนอยู่ชั้น 3 นักเรียนต้องย้ายไปเรียนห้องอื่นบ่อย ๆ และมักลืมปิดไฟกับพัดลม ครูต้องเดินขึ้นไปปิดเองหรือคอยดุนักเรียน แต่ดุทีไร นักเรียนก็เงียบไปทั้งคาบ ครูไม่ชอบบรรยากาศแบบนั้น

**แบบที่ 1**

> ถาม: ครูมีปัญหาอะไรไหมครับ
>
> ครูมะลิ: ก็ไม่มีอะไรมากนะ
>
> ถาม: เรื่องเปิดไฟทิ้งไว้ ลำบากใช่ไหมครับ
>
> ครูมะลิ: ก็ใช่
>
> ถาม: ถ้ามีเครื่องปิดไฟอัตโนมัติจะดีไหมครับ
>
> ครูมะลิ: ก็ดีนะ

**แบบที่ 2**

> ถาม: ในแต่ละวันครูทำอะไรบ้างครับ
>
> ครูมะลิ: (เล่าว่าสอน 4 คาบ ตรวจงาน ดูแลนักเรียน)
>
> ถาม: ช่วงไหนเหนื่อยที่สุดครับ
>
> ครูมะลิ: ตอนเปลี่ยนคาบ ต้องเดินขึ้นลงบันได (ถอนหายใจ)
>
> ถาม: ทำไมต้องเดินขึ้นลงครับ
>
> ครูมะลิ: ขึ้นไปดูว่าเด็กเปิดไฟทิ้งไว้หรือเปล่า
>
> ถาม: ครั้งล่าสุดที่ขึ้นไปเจอว่าเด็กเปิดไฟทิ้งไว้ เกิดอะไรขึ้นบ้างครับ
>
> ครูมะลิ: ครูก็ดุ แล้วเด็กก็เงียบไปทั้งคาบเลย ครูไม่ชอบแบบนั้น

**ชวนผู้เรียนคุย:** การสัมภาษณ์แบบไหนทำให้ได้ข้อมูลมากกว่า และคำถามไหนทำให้รู้เรื่อง "เด็กเงียบไปทั้งคาบ" จากนั้นชี้ให้เห็นว่าคำตอบ "ก็ดีนะ" ในแบบที่ 1 ยังไม่ได้ช่วยให้เราเข้าใจปัญหาของครู

## กติกาการสวมบทบาท

1. ตอบเฉพาะสิ่งที่ทีมถาม อย่าเพิ่งเล่าปัญหาที่ซ่อนอยู่หากทีมยังไม่ได้ถามถึง
2. เล่ากิจวัตรได้เต็มที่ โดยทิ้งร่องรอยให้ทีมสังเกตเห็นปัญหาที่ซ่อนอยู่ เช่น ถอนหายใจ หรือพูดถึงสั้น ๆ แล้วเปลี่ยนเรื่อง
3. เล่าปัญหาที่ซ่อนอยู่เมื่อทีมถามถึงช่วงเวลาที่เกิดปัญหา หรือถามว่า "ครั้งล่าสุด ... เกิดอะไรขึ้น"
4. เล่าความกังวลลึก ๆ เมื่อทีมถามต่อว่า "ทำไม" หรือ "รู้สึกยังไง" 2–3 ครั้ง
5. ถ้าทีมถามแบบชี้นำ เช่น "อยากได้เครื่องเตือนไหม" ให้ตอบว่า "ก็ดีนะ" แล้วหยุด
6. ถ้าทีมถามคำถามที่ตอบได้แค่ "ใช่" หรือ "ไม่ใช่" ให้ตอบสั้น ๆ
7. ไม่เสนออุปกรณ์หรือเทคโนโลยีเอง ถ้าทีมถามว่าอยากได้อะไร ให้ตอบว่า "ไม่รู้สิ ไม่เคยคิดเรื่องนี้"
8. ถ้าทีมเงียบหรือยังเขินอยู่ ให้เล่ากิจวัตรเพิ่มอีกหน่อย เพื่อให้ทีมมีเรื่องถามต่อ
9. ในขั้นที่ 4 ถ้าประโยคสรุปปัญหาตรงกับความกังวลลึก ๆ ให้ตอบว่า "ใช่เลย" ถ้าสรุปได้แค่เรื่องที่บ่นให้ฟังตอนแรก ให้ตอบว่า "ก็ใช่ แต่ที่หนักใจกว่าคือ ..." แล้วใบ้ถึงปัญหาที่ซ่อนอยู่

## บัตรผู้ใช้

บัตรแต่ละใบแบ่งข้อมูลไว้ 3 ระดับ เพื่อให้ค่อย ๆ เล่าตามคำถามของทีม

- **ปัญหาที่เล่าได้ทันที:** พูดได้ตั้งแต่เริ่มคุย
- **ปัญหาที่ซ่อนอยู่:** เล่าเมื่อทีมถามถึงช่วงเวลาที่เกิดปัญหา หรือถามถึงเหตุการณ์ครั้งล่าสุด
- **ความกังวลลึก ๆ:** เล่าเมื่อทีมถามต่อว่า "ทำไม" หรือ "รู้สึกยังไง" 2–3 ครั้ง

ท้ายบัตรแต่ละใบมีข้อมูลอีก 2 ข้อสำหรับวิทยากร **ห้ามบอกผู้เรียน**

- **ประโยคสรุปปัญหา:** ใช้เป็นแนวทางตรวจงานในขั้นที่ 2 และตอบผู้เรียนในขั้นที่ 4
- **GoGo Board ช่วยได้อย่างไร:** ใช้เป็นแนวทางแนะนำทีมตอนเลือกไอเดียในขั้นที่ 3 ผู้เรียนสามารถหาเซนเซอร์และอุปกรณ์ที่มีขายทั่วไปมาใช้เพิ่มเติมได้ ไม่จำเป็นต้องใช้เฉพาะอุปกรณ์ในชุด

ปัญหาในบัตรเลือกมาให้สอดคล้องกับทั้ง 4 หัวข้อของเวิร์กช็อป โดยส่วนที่ผู้สวมบทบาทใช้เล่าจะไม่พูดถึงเทคโนโลยี เพื่อให้ผู้เรียนเริ่มคิดจากปัญหาของผู้ใช้ก่อนคิดถึงอุปกรณ์

| 1 ป้าบัว | ✓ | ✓ | | |
| 2 แม่ชีแก้ว | ✓ | ✓ | ✓ | |
| 3 ครูสมศรี | ✓ | ✓ | ✓ | |
| 4 ยายจันทร์ | ✓ | ✓ | | |
| 5 พี่ต้น | ✓ | ✓ | ✓ | |
| 6 ลุงเอก | ✓ | ✓ | ✓ | |
| 7 ลุงแดง | | ✓ | ✓ | ✓ |
| 8 ครูนิด | ✓ | | ✓ | ✓ |
| 9 ลุงสม | ✓ | | ✓ | ✓ |

เลือกบัตรให้พอกับจำนวนผู้สวมบทบาท โดยให้บัตรที่เลือกรวมกันครอบคลุมทั้ง 4 หัวข้อ เช่น ถ้าใช้ 4 ใบ อาจเลือกบัตรที่ 2, 5, 8 และ 9

### บัตรที่ 1 ป้าบัว แม่ครัวอาสาประจำโรงครัววัด

- **ข้อมูลพื้นฐาน:** อายุ 58 ปี อาสาทำอาหารถวายพระที่วัดมา 10 ปี
- **กิจวัตร:** ตื่นตี 4 หุงข้าว ทำกับข้าว ถวายภัตตาหารเช้า ล้างจาน ทำอาหารถวายเพล ตอนบ่ายล้างจานกองใหญ่แล้วกลับบ้าน
- **ปัญหาที่เล่าได้ทันที:** ครัวร้อน ควันเยอะ
- **ปัญหาที่ซ่อนอยู่:** เวลาล้างจานหลังเพล น้ำในถังที่อยู่บนหอสูงหลังโรงครัวมักหมดกลางคัน ไม่มีใครรู้ว่าเหลือน้ำเท่าไร สวิตช์ปั๊มน้ำอยู่ที่กุฏิหลวงพี่ ป้าต้องเดินไปบอกให้ช่วยเปิดปั๊ม
- **เรื่องเล่า:** สัปดาห์ก่อนมีงานบุญ จานกองล้นอ่าง แต่น้ำหมด ต้องรออยู่ 40 นาที ระหว่างนั้นคนที่มาช่วยก็ทยอยกลับบ้านกันหมด ป้าเลยต้องล้างจานคนเดียวจนเย็น
- **วิธีที่เคยลอง:** เคาะถังฟังเสียง ฝากเด็กวัดปีนขึ้นไปดู รองน้ำใส่โอ่งไว้
- **ข้อจำกัด:** เข่าไม่ดี ปีนบันไดไม่ได้ ไม่ใช้สมาร์ตโฟน
- **ความกังวลลึก ๆ:** เกรงใจหลวงพี่ ไม่อยากไปตามทุกวัน อยากรู้ล่วงหน้าว่าน้ำใกล้หมด จะได้วางแผนเองได้
- **คำพูด:** "ป้าเกรงใจหลวงพี่ จะไปตามทุกวันก็ไม่ดี" / "น้ำชอบหมดตอนมือเต็มไปด้วยฟองทุกที"
- **ประโยคสรุปปัญหา:** "ป้าบัวต้องการรู้ล่วงหน้าว่าน้ำในถังใกล้หมด โดยไม่ต้องปีนขึ้นไปดูหรือไปตามหลวงพี่ เพราะป้าเกรงใจหลวงพี่ และไม่อยากให้มีจานค้างรอล้างจนเย็น"
- **GoGo Board ช่วยได้อย่างไร:** ใช้เซนเซอร์วัดระดับน้ำ (ลูกลอยหรืออัลตราโซนิก) ติดตั้งที่ถัง แล้วแสดงระดับน้ำด้วยไฟหรือส่งเสียงเตือนในครัว เพราะป้าไม่ใช้สมาร์ตโฟน (Automation) ส่งข้อความแจ้งเตือนไปยังโทรศัพท์ของหลวงพี่ หรือสั่งให้ปั๊มทำงานเมื่อระดับน้ำต่ำ (IoT)

### บัตรที่ 2 แม่ชีแก้ว ผู้ดูแลสวนสมุนไพรของวัด

- **ข้อมูลพื้นฐาน:** อายุ 50 ปี ปลูกฟ้าทะลายโจร ขมิ้น และตะไคร้ ให้ชาวบ้านมาเก็บไปใช้ได้ฟรี
- **กิจวัตร:** ตอนเช้ารดน้ำด้วยสายยางและเก็บใบไม้แห้ง ตอนบ่ายช่วยงานวัด บางเดือนไปปฏิบัติธรรมที่วัดอื่นครั้งละหลายวัน
- **ปัญหาที่เล่าได้ทันที:** หญ้าขึ้นเร็ว ถอนไม่ทัน
- **ปัญหาที่ซ่อนอยู่:** ช่วงที่แม่ชีไม่อยู่ ไม่มีใครรดน้ำ ต้นไม้จึงตายไปบางส่วน พอถึงหน้าฝนก็รดน้ำมากเกินไปจนรากเน่า เพราะไม่รู้ว่าดินยังชื้นอยู่หรือเปล่า
- **เรื่องเล่า:** เดือนเมษายน แม่ชีไปปฏิบัติธรรม 5 วัน ฝากเด็กวัดรดน้ำแต่เด็กลืม ฟ้าทะลายโจรเลยตายไปครึ่งแปลง ช่วงนั้นชาวบ้านเป็นหวัดกันหลายบ้าน พอมาขอสมุนไพรก็ไม่มีให้
- **วิธีที่เคยลอง:** ฝากเด็กวัดรดน้ำ คว่ำขวดน้ำปักดิน คลุมดินด้วยฟาง
- **ข้อจำกัด:** ไม่มีงบ ปลั๊กไฟอยู่ห่างจากแปลง 20 เมตร
- **ความกังวลลึก ๆ:** ชาวบ้านพึ่งสมุนไพรเวลาเจ็บป่วย แม่ชีรู้สึกผิดทุกครั้งที่กลับมาเห็นต้นสมุนไพรตาย แต่ก็ยังอยากไปปฏิบัติธรรมที่วัดอื่น
- **คำพูด:** "กลับมาเห็นต้นเหี่ยว ใจหายเลย" / "จะรดทุกวันก็ไม่รู้ว่าดินแห้งหรือยัง"
- **ประโยคสรุปปัญหา:** "แม่ชีแก้วต้องการให้ต้นสมุนไพรได้รับน้ำอย่างพอดี แม้ในวันที่แม่ชีไม่อยู่วัด เพราะชาวบ้านพึ่งสมุนไพรเวลาเจ็บป่วย และแม่ชีรู้สึกผิดทุกครั้งที่กลับมาเห็นต้นสมุนไพรตาย"
- **GoGo Board ช่วยได้อย่างไร:** ใช้เซนเซอร์วัดความชื้นในดิน แล้วสั่งให้ปั๊มทำงานหรือเปิดวาล์วรดน้ำเมื่อดินแห้ง (Automation) ให้แม่ชีดูค่าความชื้นได้แม้อยู่ที่วัดอื่น (IoT) และบันทึกค่าไว้ดูว่าดินแห้งเร็วแค่ไหนในแต่ละฤดู (Data logging)

### บัตรที่ 3 ครูสมศรี ครูเวรประจำวัน

- **ข้อมูลพื้นฐาน:** อายุ 42 ปี สอนวิทยาศาสตร์ระดับ ม.ต้น เป็นครูเวรสัปดาห์ละ 1 วัน
- **กิจวัตร:** ตอนเช้ายืนรับนักเรียนหน้าประตูและดูแลการเข้าแถว พักเที่ยงดูแลสนาม ตอนเย็นส่งนักเรียนขึ้นรถ
- **ปัญหาที่เล่าได้ทันที:** เข้าแถวนาน นักเรียนไม่ค่อยเงียบ
- **ปัญหาที่ซ่อนอยู่:** ช่วงที่มีหมอกควัน ครูเวรต้องตัดสินใจเองว่าจะให้นักเรียนเข้าแถวกลางแจ้งหรือในอาคาร ค่าฝุ่นในแอปมาจากสถานีตรวจวัดในตัวอำเภอที่อยู่ห่างออกไป 15 กิโลเมตร จึงไม่ตรงกับค่าฝุ่นที่โรงเรียน
- **เรื่องเล่า:** เดือนมีนาคมปีที่แล้ว แอปแสดงค่าฝุ่นเป็นสีเหลือง ครูเลยให้นักเรียนเข้าแถวกลางแจ้ง แต่วันนั้นชาวบ้านเผาไร่ข้างโรงเรียน ควันหนามาก นักเรียนมีอาการหอบ 2 คน ผู้ปกครองจึงโทรมาต่อว่าครู
- **วิธีที่เคยลอง:** ดูท้องฟ้า ดูค่าฝุ่นในแอป ถามครูคนอื่น
- **ข้อจำกัด:** มีเวลาเพียงไม่กี่นาทีก่อนเข้าแถวเพื่อตัดสินใจ ไม่มีงบซื้อเครื่องวัดราคาแพง
- **ความกังวลลึก ๆ:** กลัวตัดสินใจพลาดแล้วนักเรียนป่วย อยากมีข้อมูลที่เชื่อถือได้ไว้อธิบายให้ผู้ปกครองเข้าใจ
- **คำพูด:** "ครูไม่ได้อยากเดา แต่ไม่มีอะไรให้ดู" / "ตัดสินใจพลาดเมื่อไร ครูเวรต้องรับผิดชอบ"
- **ประโยคสรุปปัญหา:** "ครูสมศรีต้องการรู้ก่อนเข้าแถวทุกเช้าว่าอากาศที่โรงเรียนปลอดภัยหรือไม่ เพราะค่าฝุ่นในแอปไม่ตรงกับที่โรงเรียน และครูต้องมีข้อมูลไว้อธิบายเหตุผลในการตัดสินใจให้ผู้ปกครองเข้าใจ"
- **GoGo Board ช่วยได้อย่างไร:** ติดตั้งเซนเซอร์วัดฝุ่น PM2.5 ที่โรงเรียน แล้วใช้ไฟสีแสดงระดับฝุ่นบริเวณหน้าเสาธง (Automation) แสดงค่าบนเว็บให้ครูและผู้ปกครองดูได้ (IoT) และบันทึกค่าไว้เป็นหลักฐานประกอบการตัดสินใจ (Data logging)

### บัตรที่ 4 ยายจันทร์ ผู้สูงอายุที่อยู่บ้านคนเดียว

- **ข้อมูลพื้นฐาน:** อายุ 72 ปี หลานไปทำงานในเมือง ยายปลูกพริกไว้ขายที่ตลาดนัด
- **กิจวัตร:** เช้าเก็บพริกมาตากที่ลานหน้าบ้าน สาย ๆ ไปวัด บ่ายดูทีวีแล้วงีบ เย็นเก็บพริกเข้าบ้าน
- **ปัญหาที่เล่าได้ทันที:** ปวดเข่า หลานไม่ค่อยกลับบ้าน
- **ปัญหาที่ซ่อนอยู่:** ฝนมักตกตอนบ่าย ระหว่างที่ยายงีบหลับหรือไปวัด พริกที่ตากไว้เลยเปียก ขึ้นรา และขายไม่ได้ ยายหูไม่ค่อยดี บางครั้งจึงไม่ได้ยินเสียงฝน
- **เรื่องเล่า:** เดือนที่แล้วฝนตกตอนยายอยู่วัด พริกที่ตากมา 3 วันเปียกหมด เสียไป 2 กระด้ง คิดเป็นเงินราว 600 บาท
- **วิธีที่เคยลอง:** ฝากเพื่อนบ้านช่วยเก็บ (แต่เกรงใจ) ดูฟ้าก่อนออกจากบ้าน ลดปริมาณพริกที่ตากแต่ละครั้ง
- **ข้อจำกัด:** ใช้โทรศัพท์ปุ่มกด ยกของหนักไม่ไหว
- **ความกังวลลึก ๆ:** อยากพึ่งตัวเอง ไม่อยากให้หลานเป็นห่วง กลัวหลานจะให้ย้ายไปอยู่ในเมือง ยายใช้เงินจากการขายพริกไว้ทำบุญและซื้อกับข้าว
- **คำพูด:** "ยายไม่อยากโทรไปกวนหลาน เดี๋ยวเขาจะให้ยายย้ายไปอยู่ในเมือง" / "พริกเปียกทีหนึ่ง เสียดายแทบร้องไห้"
- **ประโยคสรุปปัญหา:** "ยายจันทร์ต้องการให้เก็บพริกได้ทันก่อนฝนตก แม้ในวันที่ยายไม่อยู่บ้าน เพราะยายอยากหาเงินเองโดยไม่ต้องพึ่งหลาน"
- **GoGo Board ช่วยได้อย่างไร:** ใช้เซนเซอร์ตรวจจับน้ำฝน แล้วสั่งมอเตอร์ให้ดึงผ้าใบมาคลุมพริก พร้อมเปิดไฟกะพริบหรือส่งเสียงดังเตือนยาย (Automation) ส่งข้อความแจ้งเตือนให้เพื่อนบ้านมาช่วยเก็บพริก (IoT)

### บัตรที่ 5 พี่ต้น ผู้เลี้ยงไก่ไข่หลังบ้าน

- **ข้อมูลพื้นฐาน:** อายุ 35 ปี ขายผักที่ตลาดตั้งแต่เช้าถึงบ่าย เลี้ยงไก่ไข่ 40 ตัว
- **กิจวัตร:** ตี 5 ให้อาหารไก่ เก็บไข่ แล้วไปตลาด กลับถึงบ้านตอนบ่ายแก่ ๆ
- **ปัญหาที่เล่าได้ทันที:** อาหารไก่แพงขึ้นทุกปี
- **ปัญหาที่ซ่อนอยู่:** หน้าร้อน เล้าไก่ที่มุงหลังคาสังกะสีจะร้อนจัดตั้งแต่เที่ยงถึงบ่าย ไก่หอบและออกไข่น้อยลง น้ำในรางก็หมดตั้งแต่เที่ยง เพราะเวลาร้อนไก่จะกินน้ำมาก
- **เรื่องเล่า:** เดือนเมษายนปีที่แล้ว พี่ต้นกลับจากตลาดมาเจอไก่นอนอ้าปากหอบ และมีไก่ตายไป 2 ตัว สัปดาห์นั้นได้ไข่ลดลงจากวันละ 30 ฟองเหลือ 18 ฟอง
- **วิธีที่เคยลอง:** ราดน้ำบนหลังคา (ทำได้เฉพาะวันที่อยู่บ้าน) ขึงตาข่ายกรองแสง ให้แม่ช่วยดู (แต่แม่ไม่ค่อยสบาย)
- **ข้อจำกัด:** ต้องขายของที่ตลาดตั้งแต่เช้าถึงบ่าย มีปลั๊กไฟใกล้เล้าไก่ แต่มีงบไม่มาก
- **ความกังวลลึก ๆ:** เงินจากการขายไข่เป็นค่าเทอมลูก แต่พี่ต้นไม่รู้เลยว่าเล้าไก่ร้อนแค่ไหนจนกว่าจะกลับถึงบ้าน
- **คำพูด:** "อยู่ตลาดก็ใจไม่อยู่ ห่วงไก่" / "ไม่รู้ว่าร้อนแค่ไหนถึงจะอันตราย"
- **ประโยคสรุปปัญหา:** "พี่ต้นต้องการให้ไก่ปลอดภัยจากความร้อนในวันที่ต้องไปขายของ เพราะต้องใช้เงินจากการขายไข่เป็นค่าเทอมลูก แต่ไม่รู้ว่าเล้าไก่ร้อนแค่ไหนจนกว่าจะกลับถึงบ้าน"
- **GoGo Board ช่วยได้อย่างไร:** ใช้เซนเซอร์วัดอุณหภูมิในตัวบอร์ด แล้วสั่งให้พัดลมหรือสปริงเกลอร์บนหลังคาทำงานเมื่ออุณหภูมิสูงเกินไป (Automation) ส่งข้อความแจ้งเตือนพี่ต้นขณะอยู่ที่ตลาด (IoT) และบันทึกอุณหภูมิไว้เทียบกับจำนวนไข่ที่ได้ในแต่ละวัน เพื่อดูว่าไก่เริ่มได้รับผลกระทบจากความร้อนที่อุณหภูมิเท่าไร (Data logging)

### บัตรที่ 6 ลุงเอก ไวยาวัจกรผู้ดูแลห้องสมุดวัด

- **ข้อมูลพื้นฐาน:** อายุ 65 ปี เป็นข้าราชการบำนาญ ดูแลห้องสมุดวัดที่มีหนังสือบริจาค หนังสือธรรมะเก่า และคัมภีร์ใบลานที่หลวงพ่อฝากไว้
- **กิจวัตร:** เปิดห้องสมุดเฉพาะวันเสาร์และอาทิตย์ คอยจัดหนังสือและทำบัตรยืม ส่วนวันธรรมดาจะปิดห้องและล็อกไว้
- **ปัญหาที่เล่าได้ทันที:** คนยืมหนังสือแล้วไม่ค่อยคืน
- **ปัญหาที่ซ่อนอยู่:** หน้าฝนหนังสือขึ้นราและมีกลิ่นอับ เพราะห้องปิดไว้ตลอดวันธรรมดาและอากาศชื้น จะเปิดหน้าต่างก็ไม่ได้เพราะฝนสาด
- **เรื่องเล่า:** หลังออกพรรษา ลุงไปต่างจังหวัด 2 สัปดาห์ พอกลับมาเปิดห้องก็เจอหนังสือธรรมะเก่าขึ้นราดำเต็มชั้น ใบลานบางผูกก็เริ่มขึ้นรา
- **วิธีที่เคยลอง:** เปิดพัดลมทิ้งไว้ (กรรมการวัดบ่นว่าเปลืองไฟ) วางถ่านดูดกลิ่น ขนหนังสือออกมาตากแดด (เหนื่อยมาก ทำได้ปีละครั้ง)
- **ข้อจำกัด:** ห้องไม่มีแอร์ ลุงไม่ได้อยู่ที่วัดทุกวัน
- **ความกังวลลึก ๆ:** หลวงพ่อฝากใบลานไว้ให้ดูแล ถ้าเสียหายก็หาใหม่ไม่ได้ ลุงจึงรู้สึกว่าต้องรับผิดชอบให้ดี แต่ไม่รู้ว่าเมื่อไรควรเปิดพัดลม เมื่อไรควรปิด
- **คำพูด:** "หลวงพ่อฝากไว้ ถ้าเสียหาย ลุงไม่รู้จะตอบท่านยังไง" / "เปิดพัดลมไว้ก็โดนว่าเปลืองไฟ ปิดก็กลัวหนังสือขึ้นรา"
- **ประโยคสรุปปัญหา:** "ลุงเอกต้องการดูแลไม่ให้ใบลานและหนังสือเก่าขึ้นราในวันที่ไม่มีใครอยู่ โดยไม่ต้องเปิดพัดลมทิ้งไว้ทั้งวัน เพราะหลวงพ่อฝากของเหล่านี้ไว้ให้ดูแล และหากเสียหายก็หาใหม่ไม่ได้"
- **GoGo Board ช่วยได้อย่างไร:** ใช้เซนเซอร์วัดความชื้นในตัวบอร์ด แล้วเปิดพัดลมเฉพาะช่วงที่ความชื้นสูงเกินไป (Automation) ให้ลุงดูค่าความชื้นจากที่บ้านได้ (IoT) และบันทึกค่าตลอดสัปดาห์ไว้ให้กรรมการวัดเห็นว่าเปิดพัดลมเท่าที่จำเป็น (Data logging)

### บัตรที่ 7 ลุงแดง อาสาดูแลจุดทิ้งขยะของหมู่บ้าน

- **ข้อมูลพื้นฐาน:** อายุ 55 ปี เป็นผู้ช่วยผู้ใหญ่บ้าน อาสาดูแลจุดทิ้งขยะรวมหน้าหมู่บ้าน
- **กิจวัตร:** เดินไปดูจุดทิ้งขยะทั้งเช้าและเย็น คอยเก็บขยะที่ตกหล่น รถขยะของ อบต. มาเก็บสัปดาห์ละ 2 วัน แต่วันเก็บไม่แน่นอน
- **ปัญหาที่เล่าได้ทันที:** ชาวบ้านไม่แยกขยะ
- **ปัญหาที่ซ่อนอยู่:** ขยะเต็มจนล้นถังก่อนรถมาเก็บ หมาคุ้ยขยะกระจายเต็มถนน ส่งกลิ่นเหม็นไปถึงบ้านใกล้เคียง ลุงไม่รู้ว่าถังจะเต็มเมื่อไร ส่วน อบต. ขอให้แจ้งล่วงหน้า 1 วัน หากต้องการให้รถมาเก็บเพิ่ม
- **เรื่องเล่า:** ช่วงสงกรานต์คนกลับบ้านกันเยอะ ขยะล้นถังอยู่ 2 วัน หมาลากถุงขยะไปทั่ว คนบ้านข้าง ๆ เลยมาต่อว่าลุง
- **วิธีที่เคยลอง:** เพิ่มถัง (แต่ขยะก็ยังล้นเหมือนเดิม) ติดป้ายให้แยกขยะ เดินไปดูวันละ 2 รอบ
- **ข้อจำกัด:** ทำฟรี ไม่มีค่าจ้าง จุดทิ้งขยะไม่มีไฟฟ้า
- **ความกังวลลึก ๆ:** ขยะล้นทีไร เพื่อนบ้านก็โทษลุง ลุงอยากมีหลักฐานไปคุยกับ อบต. ว่าควรมาเก็บบ่อยขึ้น
- **คำพูด:** "ทำดีไม่ได้ดี โดนบ่นอยู่คนเดียว" / "บอก อบต. ไป เขาก็ถามว่าเต็มบ่อยแค่ไหน ลุงก็ตอบไม่ได้"
- **ประโยคสรุปปัญหา:** "ลุงแดงต้องการรู้ล่วงหน้าว่าถังขยะใกล้เต็ม และมีข้อมูลไปบอก อบต. ว่าถังเต็มบ่อยแค่ไหน เพราะขยะล้นทีไร เพื่อนบ้านก็โทษลุง ทั้งที่ลุงอาสามาช่วยดูแลโดยไม่มีค่าจ้าง"
- **GoGo Board ช่วยได้อย่างไร:** ติดตั้งเซนเซอร์วัดระยะ (อัลตราโซนิก) ที่ขอบถัง แล้วส่งข้อความแจ้งเตือนเมื่อถังใกล้เต็ม (IoT) บันทึกว่าถังเต็มบ่อยแค่ไหนไว้เป็นหลักฐานให้ อบต. (Data logging) หรือใช้กล้องตรวจดูว่าถังเต็มแล้วหรือยัง (AI) โดยใช้แบตเตอรี่หรือแผงโซลาร์เซลล์เป็นแหล่งจ่ายไฟ เพราะจุดทิ้งขยะไม่มีไฟฟ้า

### บัตรที่ 8 ครูนิด ครูผู้ดูแลธนาคารขยะของโรงเรียน

- **ข้อมูลพื้นฐาน:** อายุ 38 ปี สอนสังคมศึกษา ดูแลธนาคารขยะของโรงเรียน
- **กิจวัตร:** สอนทั้งวัน ตอนเย็นไปดูจุดแยกขยะใต้อาคาร ซึ่งมีถัง 4 ใบสำหรับขวดพลาสติก กระป๋อง กระดาษ และขยะทั่วไป ร้านรับซื้อของเก่ามาชั่งและรับซื้อเดือนละครั้ง
- **ปัญหาที่เล่าได้ทันที:** นักเรียนดื่มนมแล้วไม่ล้างกล่อง จนมีมดขึ้น
- **ปัญหาที่ซ่อนอยู่:** ขยะเกือบครึ่งถูกทิ้งผิดถัง เพราะนักเรียนแยกไม่ออกว่าอะไรขายได้ เช่น ขวดน้ำใสกับแก้วชานม ครูต้องเทขยะออกมาคัดใหม่ทุกเย็น ใช้เวลาเกือบชั่วโมง
- **เรื่องเล่า:** เดือนที่แล้วร้านรับซื้อไม่รับขวดทั้งกระสอบ เพราะมีแก้วพลาสติกปนอยู่ เลยได้เงินน้อยกว่าที่ควรเกือบครึ่ง
- **วิธีที่เคยลอง:** ติดป้ายพร้อมรูปประกอบ (นักเรียนไม่ดู) ให้นักเรียนเวรยืนคอยบอก (ทำได้ไม่กี่วันก็เลิก) ประกาศหน้าเสาธง
- **ข้อจำกัด:** ช่วงพักเที่ยงมีคนมาทิ้งขยะมากที่สุด แต่ครูไม่ได้อยู่ตรงนั้น ใกล้จุดแยกขยะมีปลั๊กไฟ
- **ความกังวลลึก ๆ:** เงินจากธนาคารขยะนำเข้ากองทุนอาหารกลางวันสำหรับนักเรียนที่ครอบครัวขาดแคลน ครูเหนื่อยแต่ไม่อยากเลิก และไม่อยากคอยดุ อยากให้นักเรียนแยกขยะได้ด้วยตัวเอง
- **คำพูด:** "เด็กไม่ได้ตั้งใจทิ้งผิด แค่ดูไม่ออก" / "คัดขยะทุกเย็น จนไม่มีเวลาตรวจการบ้าน"
- **ประโยคสรุปปัญหา:** "ครูนิดต้องการให้นักเรียนทิ้งขยะลงถังให้ถูกประเภทตั้งแต่แรก โดยไม่ต้องมีใครยืนคอยบอก เพราะขยะที่ปนกันขายไม่ได้ราคา และเงินที่ได้ต้องนำไปเป็นค่าอาหารกลางวันให้นักเรียนที่ครอบครัวขาดแคลน"
- **GoGo Board ช่วยได้อย่างไร:** ใช้กล้องจำแนกชนิดขยะที่นักเรียนถือมา (AI) แล้วเปิดไฟบอกว่าควรทิ้งถังไหน หรือสั่งเซอร์โวให้เปิดฝาถังนั้น (Automation) พร้อมนับจำนวนขยะแต่ละชนิดไว้ดูว่ามีการทิ้งผิดถังน้อยลงหรือไม่ (Data logging)

### บัตรที่ 9 ลุงสม ชาวนาที่ต้องเฝ้านกช่วงก่อนเกี่ยวข้าว

- **ข้อมูลพื้นฐาน:** อายุ 60 ปี ทำนาข้าวเหนียว 10 ไร่ เพื่อเก็บข้าวไว้กินในครอบครัว
- **กิจวัตร:** เช้าไปนา ดูน้ำ ถอนหญ้า เที่ยงกลับมากินข้าวที่บ้าน บ่ายกลับไปนาอีกรอบ เย็นกลับบ้าน
- **ปัญหาที่เล่าได้ทันที:** ปุ๋ยแพง ค่าจ้างรถเกี่ยวแพง
- **ปัญหาที่ซ่อนอยู่:** ช่วงข้าวออกรวงใกล้เกี่ยว นกกระจอกลงมากินข้าวเป็นฝูงทั้งเช้าและเย็น ลุงต้องนั่งเฝ้าอยู่ที่ห้างนา คอยตีปี๊บไล่นกทั้งวัน จนไม่ได้ทำอย่างอื่น
- **เรื่องเล่า:** ปีที่แล้วลุงไปงานศพญาติ 2 วัน พอกลับมาก็พบว่านกกินข้าวที่มุมหนึ่งของนาไปเกือบหมด เหลือแต่รวงลีบ
- **วิธีที่เคยลอง:** ตั้งหุ่นไล่กา (ไม่กี่วันนกก็ชิน) ขึงเชือกผูกกระป๋อง ให้หลานช่วยเฝ้า (แต่หลานต้องไปโรงเรียน) เปิดวิทยุเสียงดัง (เพื่อนบ้านบ่น และนกก็ชินอีก)
- **ข้อจำกัด:** ที่นาไม่มีไฟฟ้า มีไก่ของเพื่อนบ้านและคนเดินผ่านไปมา
- **ความกังวลลึก ๆ:** ข้าวในนาเป็นข้าวที่ต้องเก็บไว้ให้ครอบครัวกินตลอดปี ลุงอายุมากขึ้น นั่งกลางแดดทั้งวันไม่ไหวแล้ว แต่ไม่อยากให้ลูกหลานต้องลาออกจากงานมาช่วย
- **คำพูด:** "นกฉลาด หุ่นไล่กาตั้งไว้ไม่กี่วันก็ไม่กลัวแล้ว" / "นั่งเฝ้าทั้งวัน ไม่ได้ทำอย่างอื่นเลย"
- **ประโยคสรุปปัญหา:** "ลุงสมต้องการป้องกันไม่ให้นกลงมากินข้าวช่วงก่อนเก็บเกี่ยว โดยไม่ต้องนั่งเฝ้ากลางแดดทั้งวัน เพราะต้องเก็บข้าวไว้ให้ครอบครัวกินตลอดปี และลุงเฝ้าเองไม่ไหวแล้ว"
- **GoGo Board ช่วยได้อย่างไร:** ใช้กล้องแยกแยะนก ไก่ และคน (AI) แล้วสั่งมอเตอร์ให้สะบัดธงหรือส่งเสียงไล่เฉพาะเมื่อมีนก โดยเปลี่ยนรูปแบบการไล่ไปเรื่อย ๆ เพื่อไม่ให้นกชิน (Automation) พร้อมบันทึกว่านกมาช่วงเวลาไหน (Data logging) ใช้แบตเตอรี่หรือแผงโซลาร์เซลล์เป็นแหล่งจ่ายไฟ
